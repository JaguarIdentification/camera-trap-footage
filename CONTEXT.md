# Jaguar Camera-Trap Dataset

This context defines the curated camera-trap artifacts and their controlled
distribution.

## Language

**Hub Distribution**:
A private, remote distribution copy of the Final Curated Snapshot, including
its media and dataset metadata.
_Avoid_: Backup, source dataset

**Image Rights Holder**:
The Jaguar ID Project, identified as the owner of the images included in the
Hub Distribution.
_Avoid_: Dataset host, repository owner
